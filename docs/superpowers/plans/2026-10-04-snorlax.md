# Snorlax Implementation Plan

> **For agentic workers:** executed inline (hackathon time box). Spec: `docs/superpowers/specs/2026-10-04-snorlax-design.md`.
> Lean plan by design: tasks, files, interfaces and verification; code lives in the repo.

**Goal:** End-to-end web demo: login → wedding profile → per-category requirements + budget → Exa research → shortlist 3 → AgentMail quote requests → poll replies → one Gemma counter-offer.

**Architecture:** One Next.js App Router app. Server-side libs in `src/lib/*` each own one integration. A background pipeline (`src/lib/pipeline.ts`) runs in-process and writes progress to Neon; the UI polls JSON routes.

**Tech Stack:** Next.js 16 + Tailwind, Neon (`@neondatabase/serverless`), `exa-js`, AgentMail REST, llama-server (OpenAI-compatible), bcryptjs + jose, vitest.
